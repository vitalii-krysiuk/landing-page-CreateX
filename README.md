# landing-page-CreateX

Createx Construction Website

Das ist eines meiner älteren und größeren Webprojekte, das ich jetzt auf GitHub hochgeladen habe.
Für dieses Projekt habe ich ein Design aus Figma als Vorlage benutzt und die Website mit HTML und CSS umgesetzt. Dabei habe ich einige Dinge aus dem ursprünglichen Design etwas verändert und an meine eigene Version angepasst.

Was gibt es auf der Website?
 - Navigation
 - Startseite
 - About Us
 - Kontaktformular
 - Unsere Services
 - Unsere Projekte
 - News
 - Kontaktbereich mit Google Maps
 - Footer
   
Verwendete Technologien
 - HTML
 - CSS

Über das Projekt

Bei diesem Projekt habe ich viel mit CSS gearbeitet. Ich habe versucht, die verschiedenen Bereiche der Website passend zum Figma-Design umzusetzen und die Elemente sinnvoll anzuordnen.
Das Projekt ist schon etwas älter, aber ich wollte es trotzdem auf GitHub hochladen, weil es eines meiner größeren Projekte ist und zeigt, wie ich meine Kenntnisse in HTML und CSS angewendet habe.
